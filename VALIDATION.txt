- ISO/XISO extraction at four supported partition offsets, direct preparation,
  TU export, source changes, unsafe paths and inventory scans.
- TU inspection/extraction without XexTool or a base game dump.
- Loopback XBDM TCP tests: fragmented framing, both recognized length byte orders,
  truncated/invalid binary responses, new-file and folder transfers, SHA-256
  readback, failed verification cleanup, existing-file protection and cancellation.

A supplied RSV2 STFS title update (Title ID 55530807, Media ID 1982EE1E) passed

Limits:
The automated tests generate synthetic fixtures; the XexTool shim does not test
actual encryption or delta processing. Real XexTool merging, real ISO/GOD inputs,
Windows GUI/EXE packaging, real XBDM connections and Xbox 360 runtime behavior
have not been tested here. The Unix executable-shim test skips on Windows.

The repository includes a GitHub Actions matrix for Windows/Linux and Python
3.10/3.12. Its remote status must be checked separately from these local results.

Compact modified TU generation is not implemented. No measured FPS or full TU
runtime compatibility claim is made.
